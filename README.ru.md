# Aot Bytecode

[English version](README.md)

Общие морфологические теги, части речи и кодировка для
[морфологического анализатора Aot](https://github.com/demidko/aot) и его
[компилятора словаря](https://github.com/demidko/aot-compiler).

Опубликованные версии доступны через [JitPack](https://jitpack.io/#demidko/aot-bytecode).
При подключении анализатора эта зависимость обычно добавляется автоматически.

`MorphologyTag.fromString("С")` возвращает тег существительного. Разбор учитывает
регистр и требует точного совпадения. Для неизвестного токена, включая `null`,
выбрасывается `IllegalArgumentException`. Метод `PartOfSpeech.partOfSpeech(tags)`
возвращает первую найденную часть речи или `null`, если её нет.

Бинарная кодировка использует ограниченное подмножество Windows-1251 и специальный
маркер конца строки. При кодировании `ё` заменяется на `е`; это не универсальный
текстовый кодек. Порядковые номера элементов перечисления входят в формат словаря:
перестановка тегов может изменить интерпретацию существующего файла.

Для проверки выполните `bash gradlew test` с совместимым JDK.
[Описание тестов и измерений](docs/compatibility.md) содержит проверяемые случаи
и команды для воспроизведения результатов. Код распространяется по
[лицензии MIT](LICENSE).
